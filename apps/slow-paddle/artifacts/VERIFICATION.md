本轮验证日期：2026-09-17；前轮记录保留于下方。

**结论：静态兼容性检查、桌面浏览器功能与移动视口检查通过；仍需在小红书 iOS / Android 容器实机验证。**

## 三颗心挑战漂流（当前版本）

- 无尽模式改为「挑战漂流」，首页和路线图首次进入即可出发。普通六关仍无生命值、无失败。
- 三颗心；浮木／礁石扣一颗，2 秒受撞保护，同一障碍不重复扣心，第三次受撞停止模拟并自动结算。软障碍及岸线不扣心；暂停菜单可主动靠岸。
- 速度从基础值的 1.1 倍逐渐增至 1.75 倍，在 2000 米达到上限；硬障碍逐段增加，行距不小于 110 世界单位，每行一个。保留可通行路线，沿用奇遇、顺流和码头奖励。
- 像素心、当前米数和下一个 250 米路标悬浮于水面；结算主按钮是「再挑战一次」。本机纪录只增不减，兼容旧存档。720×960 挑战明信片突出本次米数和个人最佳，发笔记草稿同步带入实际距离。
- **40 / 40 Node 测试通过**：新增三次扣血终止、两秒保护、同障碍去重、软障碍不扣心、普通关卡非致命、30／60／120 帧一致性、暂停冻结、速度／密度上限、分叉安全通道、纪录持久化与分享文案校验。原一小时实体回收与十分钟奇遇回收测试显式启用长保护，只验证资源上限；真实死亡规则由独立测试覆盖。
- **桌面浏览器实玩**：首次教学、拖动、三颗心耗尽自动结算（689 米／65 秒／0 心）、再挑战恢复 3 心且不重复弹教学、主动靠岸（41 米、171 米）、本机纪录仍为 689 米、刷新保留纪录及原有六关进度。生成新纪录与非纪录两种纪念图，核对本次距离与最佳距离不同的情况；无 SDK 保存保留预览并显示环境说明。未实际发布笔记。
- **移动布局**：390×844 游戏／结算／纪念图；320×568 游戏水面全高，内容和滚动宽均 316px，暂停按钮顶部 84px、44×44px，小桨 68×68px、底部距视口 20px。短屏结算收起次要指标（手记仍可查看），再挑战按钮底部 486px，无需滚动。700×320 横屏显示旋转提示并暂停，回竖屏手动恢复。浏览器日志 0 警告／0 错误。
- **构建门禁**：应用构建、严格检查、技能静态扫描、目录和 ZIP 审计通过，0 错误／0 警告。仍为经典 IIFE、相对资源、离线运行；未新增网络依赖、共享 API 或持久图片。

## 奇遇、顺流、小心愿与码头更新

- 实现四类奇遇，每段两场，按出发种子与段落轮换；小鸭跟随至鸭群、拾取瓶中信、在萤火区域慢漂、靠近隐藏码头停留。
- 顺流区域带有像素水纹与箭头提示，轻点小桨触发 3 秒滑行；不叠加普通加速，硬碰撞退出。生成时清理水流中心的硬障碍，保证引导路线可通行。
- 一趟一个小心愿，六件固定位置的码头装饰；增量奖励及时保存，重复结算不重复发放，旧存档兼容，未装备的已解锁物品不会被后续奖励重新摆上。
- 首页、结算、明信片包含个人码头；结算主要入口仍然是下一段／继续自由漂流，明信片为次要操作。
