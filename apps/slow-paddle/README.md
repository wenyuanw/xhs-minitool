# 慢桨

把日子，划慢一点。在像素水域里控制一块桨板，遇见沿途的小物，慢慢抵达下一段风景。

## 玩法

- **左右拖动**水面控制方向，有轻微惯性；轻触物品或靠近可收集。拖动不会误触收集。
- 右下角的**像素小桨按钮**带来 1.6 秒、约 20% 的轻微加速，不叠加；不按也能到终点。按钮不显示文字，只在首次教学中提示用途。
- 六段普通路线中，障碍只会轻轻弹开、减速或侧推，没有生命值与失败。越界会拉回河道。
- 到达终点获得一星；收集达到 60%、硬障碍碰撞不超过两次，分别再获一星。任意星数都解锁下一关，结算主按钮可直接进入下一段；重玩保留最佳记录。最后一关主要返回路线图，挑战漂流主要再挑战一次，明信片作为次要操作保留。
- 六段水域依次为湖心初漂、芦苇缓湾、林间双溪、峡谷回声、落日风岸、星光入海。林间、落日与入海关卡包含实际分叉。
- **挑战漂流**（无尽模式）从首次进入就开放。每次三颗心，碰浮木／礁石扣一颗并获得 2 秒保护，同一障碍不会重复扣血；第三次碰撞自动结算，也可从暂停菜单选择「靠岸结算」。不评星、不影响普通关卡解锁。
- 挑战水流从基础速度的 1.1 倍逐渐升至 1.75 倍（2000 米达到上限），障碍逐段增加至固定上限，每排只有一个硬障碍。路线随出发次数换种子，保留可通过的河道和顺流区域。
- 挑战 HUD 显示像素心、当前米数和下一个 250 米路标；结算显示本次距离、本机最佳与新纪录。挑战纪念图放大展示米数，发笔记文案带入本次距离与个人最佳。没有线上排行榜。
- 图鉴扩展为 24 件，六段水域各有四件独有小物；收集鱼类表示记录遇见，不把小鱼带走。
- 水面另有可拾取的贝壳，靠岸后存入本地账户。可用贝壳解锁 6 位轮廓不同的漂流搭档；角色能力分别影响拾贝收益、划桨持续、转向、碰撞减速或航速。
- 三款桨板不再只是换色：薄荷狭舟、珊瑚双鳍、星河尖舟拥有不同轮廓和花纹，后两款分别在完成第三、六关后解锁。
- 可选随关卡、白昼、黄昏、夜晚。声音默认关闭，在页面角落用图标直接开关；开启后首页、路线、图鉴、码头、装扮、设置、漂流和结算都有各自的离线合成旋律，拾贝、新图鉴、解锁、选择、划桨、碰撞和靠岸均有独立音效。

## 界面与纪念图

所有页面沿用水域的像素配色、方角控件和本地像素图标。首页以湖景为主体；说明、奇遇故事、存档信息和详细结算按需打开。标题用本地生成的像素字，正文保持系统中文的清晰度。分享图片统一在像素画布生成，数字采用本地位图，图片始终为 720×960。

## 水上的新鲜事

- 每段水域出现两场不同的奇遇，随出发次数和自由漂流段落轮换，种子可复现。四类分别为送小鸭回家、瓶中来信、萤火微光和隐藏码头。靠近参与，瓶中信也可轻点；没有倒计时惩罚。
- 发光水流中轻点小桨，可获得 3 秒、约 35% 的顺流滑行与水花反馈；和普通加速不叠加，每条水流只计一次。硬碰撞会退出滑行；普通路线没有失败，挑战漂流会按生命规则扣心。
- 每趟只有一个小心愿：收集四件小物、顺流一次，或完成一次奇遇。自由漂流跨段不会重复发放心愿；没有每日任务和连续登录要求。
- 「我的码头」有六种固定位置的装饰：靠岸木椅、野花盆栽、顺风小旗、小鸭木雕、瓶中来信、萤火小灯。对应奇遇、心愿与滑行解锁后自动摆放，也能收起或重新摆上。
- 奖励获得后立即合并保存，返回路线图或中途关闭不会撤销已经保存的奖励。首页、结算和明信片会展示自己的码头，结算同时记录本次心愿、滑行和奇遇。

## 开发与打包

在仓库根目录运行：

```sh
pnpm install
pnpm dev:slow-paddle
pnpm --filter slow-paddle test
pnpm --filter slow-paddle build
pnpm --filter slow-paddle validate
```

- 提交目录：`apps/slow-paddle/xhs-tool/`
- 离线包：`apps/slow-paddle/slow-paddle-xhs-tool.zip`
- 最终 ZIP 根目录包含唯一 `index.html`、经典 `app.js`、`app.css` 与本地图标。无需网络、CDN、服务器、安装 PWA 或请求传感器权限。
- 本地开发服务器只用于预览，不在 ZIP 中。源码使用 ES 模块，Vite 明确以 ES2017 / Chrome 61 为目标，打包为 IIFE。

## 验证

`pnpm --filter slow-paddle test` 使用 Node 内置测试运行器，覆盖游戏规则、长时运行、操作手势和原生接口适配。

浏览器验收脚本需要测试环境提供 Playwright 与 Chromium，**它们不是游戏或 ZIP 的依赖**。使用已安装的 Playwright：

```sh
# 已能正常解析 playwright 时：
node apps/slow-paddle/tests/browser-smoke.mjs

# 或明确指定已有运行时的绝对模块路径：
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node apps/slow-paddle/tests/browser-smoke.mjs
```

另可运行 `tests/browser-edge.mjs` 检查严格 CSP、原生存储模拟、触摸及异常界面；具体结果见 [验证报告](artifacts/VERIFICATION.md)。

脚本直接加载最终离线文件，断开网络，使用真实 DOM 操作与虚拟时钟逐关运行，输出 `artifacts/browser-report.json` 和截图。虚拟时钟不改变游戏规则或向生产代码加入测试接口。它不能替代手机触摸手感、真机帧率与小红书容器验收。

静态检查与包体审计：

## 存档和平台能力

业务 key 为 `slow-paddle-save-v1`，保存挑战最佳米数、挑战教学状态、图鉴、贝壳余额、角色解锁与当前角色、最高成绩、桨板、设置、首次操作教学，以及出发次数、奇遇／心愿／滑行累计和码头摆放。老存档缺少的新字段会安全补齐，原有关卡进度保持。当前局位置不保存。关闭后再次打开返回路线图，关卡重新开始；切后台或横屏会暂停，回到竖屏后手动继续。

客户端 9.46.0+ 优先使用原生 Storage；低版本或未知版本使用浏览器存储。原生后端错误不会悄悄改用浏览器存储。读入失败时保护旧记录，仅在内存游玩，可在设置重试；写入按顺序执行，失败可重试。升级迁移仅在确认原生 key 缺失时执行，成功写入后清除旧副本。重置仅删除本游戏 key，需在游戏内明确确认。缓存不承诺永久保存。

结算后可以生成 720×960 明信片。用户主动点击后，通过 `writeTempFile`、`saveImageToPhotosAlbum` 保存图片，或通过 `postNote` 带入图片和文案，继续在小红书编辑发布。无 SDK、拒绝权限或取消时保留明信片预览，不伪报成功，不使用下载链接或外部跳转。发笔记依赖 App 发布流程，不承诺断网发布与审核结果。

没有重力感应、振动、远程素材、PWA、Worker、网络 API 或音频文件。背景音乐与音效均由本地 Web Audio 实时合成，依赖用户首次手势开启，不支持时静音。

## 结构

- `src/game/`：关卡数据、固定步长模拟、奇遇与心愿奖励、触摸输入、像素渲染与明信片。
- `src/lib/`：存储、音效与原生媒体接口。
- `src/main.js`：单页流程、HUD、暂停、收藏、设置和结算。
- `tests/`：逻辑、接口与浏览器验收。
- `artifacts/`：截图、浏览器报告与验证记录，不进入 ZIP。

真实小红书 iOS / Android 容器的原生持久化、保存相册、笔记编辑页、权限与最低版本兼容性，需要在目标设备进一步验证；桌面浏览器检查通过不能等同于真机通过。
